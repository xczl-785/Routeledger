# RouteLedger Codex plugin 0.9.5 candidate

RouteLedger 0.9.5 is an unpublished local candidate focused on MCP contract
clarity and review readiness. It does not change the persisted RouteLedger
Version model or migrate historical L3 action types.

## Changes

- Corrects Mission Control read-only declarations and ordinary-write/L3 commit
  idempotency hints; freezes the seven directly destructive tools in a contract
  test.
- Renames nine proposal-producing MCP tools so the advertised name says
  `preflight`, `preview`, or `propose`. Previous names remain callable as
  unadvertised compatibility aliases.
- Adds exact structured `outputSchema` contracts to 10 priority task-level
  tools and validates returned structured content before sending it to an MCP
  client. Contract drift returns `INVALID_TOOL_OUTPUT`.
- Keeps the public surface at 49 tools and leaves stored L3 `actionType` values
  unchanged.

## Release state

This file documents a candidate only. No tag, GitHub Release, push, merge, or
installed-plugin update is implied until the normal release gates are run and
publication is explicitly authorized.
