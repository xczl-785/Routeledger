# RouteLedger Codex plugin 0.4.2

## Release

This patch repairs the canonical persistence and usability regressions found by
the 0.4.1 empty-project evaluation. It is fixed by immutable tag
`routeledger-plugin-v0.4.2` on `main`.

### Highlights

- Canonical pending-operation JSON now round-trips `fromVersionId` and
  `setAsCurrent`, keeping `create_version` and `advance_to_version` approval
  digests stable after process restart.
- Proposal creation reloads the persisted operation and verifies its digest
  before returning it for approval. A lossy persistence adapter fails early and
  rolls the proposal back.
- A blocked `advance_to_version` returns structured gate diagnostics without
  creating a pending proposal.
- SQLite migration `0006` admits `advance_to_version` pending operations and
  approval artifacts while preserving existing approval history.
- `create_version` review text and blocked advance diagnostics honor
  `responseLocale`; Todo reads preserve explicit batch order when timestamps
  are equal.
- Plugin runtime identity explicitly reports
  `provenanceStatus=external_attestation_required`. The runtime payload remains
  content-addressed, while tagged CI binds the final source commit and full
  plugin distribution digest without inventing self-referential inline values.
