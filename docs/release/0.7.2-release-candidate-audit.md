# RouteLedger Codex plugin 0.7.2 release-candidate audit

Status: source and distribution gates passed; cross-platform CI and merged-main Desktop acceptance pending

Planned immutable release: `routeledger-plugin-v0.7.2`

## Scope

This candidate supersedes 0.7.1 after a Windows Desktop retest proved that the
correct 0.7.1 runtime and digest could still lack `CODEX_PERMISSION_PROFILE`,
leaving `approve_l3_operation` unavailable before any authorization UI.

The acceptance target is:

1. installed runtime reports plugin/runtime 0.7.2 and its committed payload digest;
2. missing permission-profile environment reports native host management, not an unavailable control plane;
3. explicit propose, approve, and commit creates and consumes one exact `host_admission` artifact;
4. one-call execution preserves the same exact grant, receipt, live validation, and atomic commit semantics;
5. exact installed identity receives no false update/restart recovery loop;
6. full source, package, plugin, marketplace, and cross-platform CI gates pass.

## Release boundary

Merge through protected `main`, update the marketplace installation, and run
Desktop acceptance from a new task. Create `routeledger-plugin-v0.7.2` only
after that acceptance succeeds.
