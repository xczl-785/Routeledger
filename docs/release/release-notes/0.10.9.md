# RouteLedger Codex plugin 0.10.9

RouteLedger 0.10.9 removes three avoidable sources of Agent friction while
preserving the existing state machine, authorization levels, and English
control-plane contract.

## Changes

- Omits README and other human-entry-document metadata from successful
  `agent_only` project initialization responses. Explicit document inspection
  and human-review profiles retain the information.
- Returns a three-step, dependency-aware recovery plan when Deferred creation
  has no real downstream Version: propose the Version, execute the admitted
  proposal, then retry the original request with the proposal's real target ID.
- Adds `contentLocale.scope: "project_content_only"` to runtime inspection,
  including compact output, so Agents can distinguish project content language
  from the stable English control plane without a localization subsystem.

## Compatibility

Public tool names, inputs, lifecycle and L3 rules, persisted project data, and
control-plane language are unchanged. The initialization response removes only
human-oriented documentation metadata under `agent_only`; other interaction
profiles remain compatible.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.9` on `main`.
