# RouteLedger Codex plugin 0.7.1 release-candidate audit

Status: source and distribution gates passed; Desktop acceptance pending on merged `main`

Planned immutable release: `routeledger-plugin-v0.7.1`

## Scope

This candidate supersedes untagged 0.7.0 after a Windows Desktop regression
proved that same-version marketplace updates could leave an older MCP process
running with an indistinguishable version identity.

The acceptance target is:

1. installed runtime reports plugin/runtime 0.7.1 and the committed payload digest;
2. `get_l3_authorization_status` returns `profileCompatible` and a resolved
   Codex effective mode without requiring a RouteLedger profile;
3. `execute_l3_operation` can create the first Version from an empty route;
4. unavailable permission context returns update, restart, and verification actions;
5. full source, package, plugin, marketplace, and cross-platform CI gates pass.

## Release boundary

Merge through protected `main`, update the marketplace installation, and run
Desktop acceptance from a new task. Create `routeledger-plugin-v0.7.1` only
after that acceptance succeeds.
