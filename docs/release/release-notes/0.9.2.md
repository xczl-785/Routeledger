# RouteLedger Codex plugin 0.9.2

RouteLedger 0.9.2 is the first published plugin release with Mission Control
available directly from the installed Codex plugin.

## Plugin-native Mission Control

- `open_mission_control` launches or reuses the local read-only UI Hub without
  requiring a source checkout.
- Explicitly registered projects share one loopback-only Hub and can be
  switched without changing MCP binding or canonical RouteLedger data.
- Launcher, project registry, packaged UI assets, and plugin smoke coverage are
  included in the JSON-only runtime.

The release is fixed by immutable tag `routeledger-plugin-v0.9.2` on `main`.
