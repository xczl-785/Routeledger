# RouteLedger Codex plugin 0.7.0

RouteLedger 0.7.0 reduces L3 route changes to one exact, idempotent decision call while preserving
proposal, decision, artifact, commit-time validation, receipt, and audit semantics. The candidate
becomes the published release only after protected-branch CI, real Codex Desktop acceptance from
`main`, and immutable tag `routeledger-plugin-v0.7.0`.

## Decision protocol

- `execute_l3_operation` owns the end-to-end proposal, decision, artifact, and commit chain.
  Concurrent duplicates share one in-flight execution; exact retries replay without a second
  authorization consumption or mutation.
- New high-level responses expose `decisionArtifact`; persisted `ApprovalArtifact` records and the
  low-level propose/approve/reject/commit tools remain readable and compatible.
- Authorization status defaults to product fields such as effective mode, availability, limits,
  and waiting reason. Profile IDs, digests, revisions, and epochs require explicit
  `detail=internal` diagnostics.

## Host adapters

- Codex permission profiles map explicitly to interactive, delegated, and finite preauthorized
  RouteLedger modes. Missing or unknown host context fails closed unless an explicit plugin
  fallback is configured.
- MCP `2025-11-25` structured elicitation remains compatible.
- MCP `2026-07-28` supports `server/discover`, per-request negotiation, native
  `InputRequiredResult`, keyed `inputResponses`, and integrity-protected `requestState` recovery.
  Generic MCP never infers Codex mode.
- 2026 L3 request state requires the host-owned
  `ROUTELEDGER_MCP_REQUEST_STATE_SECRET`; tamper, expiry, changed arguments, response-only retry,
  and a wrong restart secret fail before authorization consumption.

## Compatibility and boundaries

- Canonical JSON schemas are unchanged. Legacy authorization artifacts, readers, exact replay,
  finite grants, receipts, V1 authority config, V2 broker profiles, and low-level tools remain.
- This release is local and single-user. It does not add remote authority, organizations, OAuth,
  multi-user policy, cross-device state, or npm publication of `@routeledger/mcp`.
- `codex-marketplace` remains the protected historical 0.3.3 branch. The release is built and
  tagged only from `main`.

## Release gates

- Full tests, typecheck, lint, generated plugin/runtime checks, Git marketplace smoke, previous
  `routeledger-plugin-v0.6.0` comparison, native host smoke, and the three Codex permission modes
  must pass in the documented order.
- The immutable tag triggers cross-platform CI and publishes
  `routeledger-plugin-v0.7.0-attestation.json` as the durable GitHub Release checksum manifest.
