# RouteLedger Codex plugin 0.9.6 candidate

RouteLedger 0.9.6 is an unpublished local candidate focused on first-use agent
clarity. It does not weaken RouteLedger binding checks or the exact L3 approval
and commit chain.

## Changes

- Returns a successfully persisted Version-structure proposal as `ok: true`
  with `status: confirmation_required`, clearly separating pending approval
  from a failed proposal.
- Reports the current public `configure_project` follow-up after an explicit
  binding is activated, without stale session-activation or restart guidance.
- Guides Deferred creation toward proposing a downstream Version when no legal
  target exists, while leaving execution behind the existing L3 authorization
  boundary.
- Uses the selected composite-tool operation to report precise schema paths and
  names unexpected fields in validation errors.
- Updates both bundled RouteLedger Skills so agents handle pending proposals
  and empty downstream routes without unsafe retries.
