# RouteLedger Codex plugin 0.9.1

RouteLedger 0.9.1 is a patch candidate for testing the Mission Control UI and
the agent-facing recovery fixes completed after the 0.9.0 distribution was
built.

## Recovery and route guidance

- Document-drift checks now distinguish completed, partial, and not-completed
  outcomes when entry files cannot be read.
- Closed route tails, residual audits, duplicate Todo closes, invalid Deferred
  targets, and stale create-Version requests return actionable next steps.
- Stale L3 approvals remain fail-closed while exposing the live gate difference
  and a safe recovery chain.
- Successfully persisted advance proposals return a structured confirmation
  state instead of a top-level failure.

## Runtime and Mission Control

- Routine MCP responses carry compact runtime metadata while the explicit
  runtime diagnostic tool retains the full context.
- The bundled read-only multi-project Mission Control UI includes the latest
  route navigation and Hub lifecycle changes from the 0.9.0 candidate.
