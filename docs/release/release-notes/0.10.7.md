# RouteLedger Codex plugin 0.10.7

RouteLedger 0.10.7 reduces the context cost of repeated Agent reads while
preserving the full standard and audit-oriented response contracts.

## Changes

- Adds operation-aware compact projections for runtime, current-context,
  next-action, Version-list, L3-proposal-list, and Todo receipt responses.
- Omits empty routine collections and repeated nonessential metadata from
  compact reads while retaining exact next actions, active blockers, and
  write receipts.
- Uses a short text acknowledgement for explicit compact calls over the 2026
  MCP transport, avoiding a second full copy of `structuredContent` where the
  host supports it. Legacy and standard responses keep the compatible mirror.
- Adds response-footprint budgets, integration coverage, and a repeatable
  measurement command.

## Compatibility

Public tool names, write semantics, standard responses, legacy transports,
lifecycle rules, approval rules, and the JSON-first source of truth are
unchanged. Compact responses intentionally omit fields classified as routine
or recoverable through a standard follow-up read.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.7` on `main`.
