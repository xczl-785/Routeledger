## Recovery and negative matrix

- duplicate and concurrent one-call delivery: one proposal, one authority call, one commit;
- sequential retry: exact commit replay without a second mutation;
- process restart: signed 2026 request state resumes the original pending proposal;
- request tamper, changed arguments, response-only retry, expiry, and wrong secret: fail before
  authorization consumption;
- stale snapshot, commit concurrency, revoke-versus-commit, post-save receipt recovery, legacy
  replay, disabled/mismatched profiles, and unavailable host permission context: existing negative
  suites remain green;
- missing 2026 request-state secret: fail before proposal creation;
- disconnect and JSONL timeout: pending work fails closed and late responses are not accepted.
