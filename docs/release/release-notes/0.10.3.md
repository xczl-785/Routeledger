# RouteLedger Codex plugin 0.10.3

RouteLedger 0.10.3 makes agent-facing operational text deterministic across
route states and MCP inspection surfaces.

## Changes

- Uses canonical English for next-action summaries, reasons, and decision
  conditions, regardless of the Project `contentLocale`.
- Renders coded gate blockers through one message catalog across current
  context, direct gate inspection, and Version legal-operation projections.
- Normalizes document-drift warnings, coverage limitations, and summary text
  while preserving Project-authored values embedded in diagnostics.
- Keeps candidate Todo titles and reasons, along with documentation templates,
  in the Project `contentLocale`.
- Adds regression coverage for decision guidance, cross-endpoint blocker text,
  unreadable entry documents, and localized candidate Todos.

## Compatibility

Tool names, JSON fields, enums, record IDs, and error codes are unchanged.
Existing Project content is not translated or rewritten.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.3` on `main`.
