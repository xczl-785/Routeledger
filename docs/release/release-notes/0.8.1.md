# RouteLedger Codex plugin 0.8.1

RouteLedger 0.8.1 is a non-functional architecture and release-hardening
update. It preserves the RouteLedger tool, canonical JSON, binding, lifecycle,
and exact L3 authorization contracts introduced in 0.8.0.

## Internal architecture

- MCP tool registrations and handlers are organized by Binding, Mission
  Control, Context, Version, Work, and L3 capability behind the unchanged
  registry facade.
- Shared MCP tool contracts and transport schemas have explicit leaf-module
  ownership, while cross-capability order, preflight, session composition, and
  disposal remain in the composition root.
- Version closeout summary and planning orchestration is isolated behind the
  unchanged `RouteLedgerService` public application facade.

## Compatibility and assurance

- The full MCP profile remains 48 tools and the JSON-only plugin profile
  remains 46 tools, with unchanged order, schemas, annotations, risk metadata,
  and response behavior.
- Canonical JSON and storage semantics are unchanged. The deferred persisted
  commit-owner recovery gap remains explicit and is not altered by this
  refactor.
- Characterization, focused security tests, the full repository suite, runtime
  generation checks, and independent staged audits cover the refactor.

The release is fixed by immutable tag `routeledger-plugin-v0.8.1` on `main`.
Tagged CI and fresh-host acceptance bind that source commit to the published
runtime and distribution checksums.
