# RouteLedger Codex plugin 0.10.0 candidate

RouteLedger 0.10.0 is an unpublished candidate that separates the agent
protocol language from user-facing project content.

## Changes

- Removes `responseLocale` from every public MCP tool and from server startup
  configuration.
- Returns canonical English system messages, action guidance, and diagnostics
  to agents while preserving user-authored content unchanged.
- Stops inferring `contentLocale` from the agent or host language; the agent
  must obtain an explicit user choice before initialization or further writes.
- Keeps the persisted `contentLocale` contract and UI consumption path intact.
- Replaces the bilingual MCP response layer with a smaller agent-response
  normalizer based on stable codes, action types, and structured details.

## Compatibility

This is a breaking agent-protocol cleanup: callers that send `responseLocale`
must remove that field. Historical project data and `contentLocale` remain
compatible.

## Release state

This file documents a candidate only. No tag, GitHub Release, marketplace
publication, or installed-plugin update is implied until the normal release
gates are run and publication is explicitly authorized.
