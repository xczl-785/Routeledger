# RouteLedger Codex plugin 0.10.2

RouteLedger 0.10.2 reduces canonical repository noise and shortens admitted
Version lifecycle workflows without weakening exact authorization.

## Changes

- Makes new JSON-only projects use compact operation envelopes by default while
  preserving existing loose-audit projects until explicit migration.
- Adds initialization-time, non-blocking human entry-document coverage guidance
  without rewriting README or other project documents.
- Returns a localized decision branch when a running Version has no open Todo.
- Adds `execute_admitted_proposal`, allowing a persisted lifecycle proposal to
  resume by `pendingOperationId` and complete authorization plus commit inside
  one admitted high-risk call.
- Keeps explicit approve, reject, and commit operations for fine-grained hosts
  and retains exact digest, binding, gate, receipt, and replay checks.

## Compatibility

Existing loose canonical JSON remains readable and writable in its current
layout. Existing explicit `propose -> approve -> commit` clients remain
supported. The new execution operation is additive within the existing public
`execute_route_change` composite tool.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.2` on `main`.
