# RouteLedger Codex plugin 0.9.0

RouteLedger 0.9.0 adds the portable read-only Mission Control UI to the Codex
plugin without changing canonical JSON or write authorization semantics.

## Read-only UI Hub

- One local Hub process serves all explicitly registered RouteLedger projects;
  the page displays one project at a time and switches without changing MCP
  binding or writing project data.
- Repeated opens reuse the healthy Hub. The Hub listens only on `127.0.0.1`,
  stops explicitly from the page or CLI, and exits after 30 idle minutes.
- Project selection, historical and future Version inspection, status labels,
  and approval history remain read-only.

## Portable plugin runtime

- The JSON-only plugin runtime now carries the built UI assets and launcher,
  while continuing to exclude SQLite and `better-sqlite3`.
- `open_mission_control` and `get_mission_control_status` are available in both
  full and JSON-only profiles.
- Package and plugin smoke tests verify portable startup, canonical project
  reads, multi-project reuse, explicit shutdown, and idle cleanup.
