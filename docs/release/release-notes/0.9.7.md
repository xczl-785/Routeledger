# RouteLedger Codex plugin 0.9.7 candidate

RouteLedger 0.9.7 is an unpublished local candidate focused on making
`next_action` guidance accurate and directly usable by agents.

## Changes

- Keeps pending proposal facts intact instead of accidentally localizing them
  as the selected route action.
- Makes a ready Version's start guidance explicit about proposal, L3 approval,
  and exact execution.
- Returns concrete follow-up tool input for ready Versions and pending
  proposals.
- Projects recommended internal operations onto the public plugin tool surface,
  so agent-facing responses no longer suggest internal tool names.

## Release state

This file documents a candidate only. No tag, GitHub Release, marketplace
publication, or installed-plugin update is implied until the normal release
gates are run and publication is explicitly authorized.
