# RouteLedger Codex plugin 0.8.0

RouteLedger 0.8.0 replaces reusable authorization scopes with an exact,
single-use authorization for each pending proposal. The authorization binds
proposal, project, RouteLedger root, action, target, and operation digest.

## Exact-only authorization

- Codex native admission, generic MCP approval, delegated authority, and the
  user-visible preauthorized mode all mint a fresh decision for one proposal.
- Standing policy is evaluated for each proposal; it does not create a reusable
  session or time-window credential.
- Approval receipts use one atomic claim/finalize lifecycle across every
  authorization source. Live gate and digest validation still run before the
  canonical mutation.
- Generic elicitation exposes only approval of the current proposal. Decline
  rejects it; cancellation or malformed input leaves it pending and creates no
  artifact.

## Migration and compatibility

- Host authority state, profile state, canonical JSON, and SQLite migrate to
  exact-only records. Legacy grants are revoked and tombstoned and require a
  new authorization.
- Previously committed legacy approval artifacts remain readable as immutable
  audit history, but cannot authorize or replay a mutation.
- Resume state seals and revalidates the full exact binding after restart.

The immutable tag remains withheld until merged-main, platform, and fresh-host
acceptance are complete.
