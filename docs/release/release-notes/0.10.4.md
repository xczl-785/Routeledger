# RouteLedger Codex plugin 0.10.4

RouteLedger 0.10.4 improves the Agent-first workflow and reduces the context
cost of long MCP action loops.

## Changes

- Clarifies that `contentLocale` governs Agent-authored project content while
  control-plane diagnostics and protocol text remain canonical English.
- Uses neutral host-authority language for Codex admission instead of implying
  that a fixed synthetic user identity approved an L3 operation.
- Makes recommended write and high-risk actions directly executable by carrying
  the active `expectedRouteLedgerRoot`, target identifiers, proposal ID, and
  exact operation digest when available.
- Adds an `interactionProfile` and keeps Mission Control or human-entry setup
  advisory in Agent-only hosts, without blocking route work.
- Adds `detail: compact | standard | audit` across the public MCP surface.
  Compact responses retain actionable state, blockers, IDs, L3 safety evidence,
  and executable next actions while summarizing events and omitting audit-heavy
  payload bodies. Standard remains the compatibility default.
- Reports compact-response byte size and exact omitted sections, with regression
  coverage proving that compact L3 responses can still complete and replay an
  exact route change.

## Compatibility

Omitting `detail` preserves the existing standard response. Persisted project
data, lifecycle states, tool names, error codes, authorization digests, and
idempotency semantics are unchanged.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.4` on `main`.
