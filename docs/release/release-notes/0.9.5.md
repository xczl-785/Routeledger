# RouteLedger Codex plugin 0.9.5 candidate

RouteLedger 0.9.5 is an unpublished local candidate focused on MCP contract
clarity and review readiness. It does not change the persisted RouteLedger
Version model or migrate historical L3 action types.

## Changes

- Corrects Mission Control read-only declarations and ordinary-write/L3 commit
  idempotency hints; freezes the seven directly destructive tools in a contract
  test.
- Reduces the public MCP surface from 49 low-level tools to 11 task-level
  tools: 2 read-only, 8 ordinary write, and 1 high-risk. Former public names
  are not retained as aliases.
- Uses `operation` to select a task-level workflow, keeping business fields
  such as Deferred review `action` independent and collision-free.
- Keeps low-level capability registrations inside the server so the merge does
  not remove route behavior. Host-config rendering/writing remains an
  internal/CLI installation capability rather than an Agent-facing MCP tool.
- Publishes a structured response envelope for every public tool and validates
  returned structured content before sending it to an MCP client. Contract
  drift returns `INVALID_TOOL_OUTPUT`.
- Leaves persisted L3 `actionType` values unchanged.

## Release state

This file documents a candidate only. No tag, GitHub Release, push, merge, or
installed-plugin update is implied until the normal release gates are run and
publication is explicitly authorized.
