# RouteLedger Codex plugin 0.10.1

RouteLedger 0.10.1 improves agent-facing runtime diagnostics and reduces the
Git review noise produced by long-lived canonical audit history.

## Changes

- Makes persisted lifecycle proposals consistently return
  `confirmation_required` with exact approve and reject inputs.
- Reports binding filesystem effects, scoped runtime build provenance, and one
  unified storage blocking issue while retaining compatibility fields.
- Clarifies idempotent replay as an immutable original-commit result and points
  callers to refreshed current context.
- Adds managed LF and GitHub Linguist generated-file attributes for canonical
  audit paths while preserving existing project-specific attributes.
- Adds `json audit-summary` for operation, semantic, and physical Git-diff
  summaries.
- Adds explicit operation envelopes and closed-Version audit packs with
  digest verification, immutable packed history, and transparent logical reads.

## Compatibility

Loose canonical JSON remains readable. Audit compaction is explicit and does
not change the logical codec, validator, or SQLite aggregate schema. Existing
agent response fields remain available during the compatibility period.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.1` on `main`.
The tag and durable checksum attestation are created only after host testing of
the merged candidate succeeds.
