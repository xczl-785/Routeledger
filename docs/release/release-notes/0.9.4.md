# RouteLedger Codex plugin 0.9.4

RouteLedger 0.9.4 adds persistent idempotency protection to ordinary writes so
an exact retry can replay its result instead of duplicating canonical work.

## Ordinary-write idempotency

- Ordinary write tools persist idempotency receipts alongside canonical JSON
  state and replay exact retries across process restarts.
- Reusing a key with different input fails closed instead of silently applying
  a second operation.
- JSON validation, SQLite read-model migration, MCP input handling, and package
  smoke coverage include the new receipt data.

The release is fixed by immutable tag `routeledger-plugin-v0.9.4` on `main`.
