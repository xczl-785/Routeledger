# RouteLedger Codex plugin 0.9.3

RouteLedger 0.9.3 adds localized, agent-facing Mission Control guidance while
preserving the 0.9.2 UI and binding semantics.

## Localized runtime guidance

- Runtime responses distinguish when Mission Control is unavailable, ready to
  open, already running, or incompatible.
- Human-readable notices follow the requested response locale while stable
  tool names, fields, enums, and error codes remain unchanged.
- Tests cover localized notices, launcher recovery, and packaged runtime
  behavior.

The release is fixed by immutable tag `routeledger-plugin-v0.9.3` on `main`.
