# RouteLedger Codex plugin 0.4.3

## Release candidate

This patch closes the provenance-discovery and document-drift usability gaps
reported after the 0.4.2 empty-project regression pass. It remains a candidate
until merged to `main` and fixed by immutable tag
`routeledger-plugin-v0.4.3`.

### Highlights

- Plugin runtime identity now exposes a stable detached-attestation locator.
- Tag CI retains its short-lived workflow artifact and also publishes the
  verified attestation as a durable GitHub Release asset.
- Document-drift suggestions aggregate multiple stale current-Version fields
  into one Todo per file while retaining each warning and reason.
- `当前状态` / `current status` is recognized only near an explicit current-Version
  declaration, avoiding broad README false positives.
- Coverage results include copyable Chinese and English declaration templates.

## Required release evidence

- Full workspace test, typecheck, and lint gates.
- Codex plugin and Git marketplace smokes.
- Release metadata comparison against `routeledger-plugin-v0.4.2`.
- Tag workflow test proving one verified attestation is published both as a CI
  artifact and as the stable GitHub Release asset named by runtime identity.
