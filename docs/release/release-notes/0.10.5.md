# RouteLedger Codex plugin 0.10.5

RouteLedger 0.10.5 completes the code-health roadmap without changing the
agent-facing tool names or the JSON-first source-of-truth model.

## Changes

- Extracts cohesive query, Version, Batch, proposal, approval, authorization,
  and commit use cases behind narrow internal application boundaries.
- Validates MCP tool input before binding and authorization, while preserving
  protocol-specific response projection and exact L3 authorization behavior.
- Replaces Core filesystem access with a containment-safe document-source port.
- Makes WorkItem lineage explicit while retaining legacy `Undo(wait)` audit
  history and rejecting conflicting current Todo/Deferred children.
- Replaces hidden aggregate revision metadata with explicit JSON and SQLite
  optimistic-concurrency tokens, including transactional SQLite CAS.
- Adds real headless Mission Control process coverage and enforceable workspace
  coverage floors.
- Makes successful storage revisions non-null and fails closed when an external
  writer violates that contract.
- Fixes the combined release-check command so `--previous-ref` and tag arguments
  reach the plugin distribution/version guard.

## Compatibility

Canonical JSON remains the source of truth and its serialized bytes do not gain
the runtime-only aggregate revision. Existing Todo plus retained legacy Undo
projects remain readable. The public MCP tool names and normal agent workflow
remain unchanged.

## Release state

The release is fixed by immutable tag `routeledger-plugin-v0.10.5` on `main`.
